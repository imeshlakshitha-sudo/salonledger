Privacy Policy

Where your data lives

In this version everything you enter (income, expenses, saved packages, profile) is stored only in your browser’s localStorage on this device. SalonLedger has no server and sends nothing anywhere.

Demo vs. Live data

Demo Mode uses sample data in its own storage area. Live Mode uses a separate area for your real salon data. Switching modes never copies, mixes or overwrites either one.

Your control

Use Clear Live Data to erase live entries, or clear your browser’s site data to remove everything. Because data is local, clearing the browser or switching devices will remove access to it, so download a monthly CSV as a backup.

When cloud sync arrives

If optional cloud sync is added later, it will be opt-in, this policy will be updated first, and you will be told what is stored, where, and how to delete it. Local-only use will stay available.
